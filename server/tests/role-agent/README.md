# 岗位 Agent 测试命令（role-agent）

5 个岗位 Agent（仓管 / 领料员 / 采购员 / 老板 / 后台管理员）跑「端到端全流程 + 两端一致性」，
接口层 3 轮 + 真实浏览器 UI 层 1 轮。发现 P0/P1 即退出码 1。

## 用法

```bash
cd server

# 一键全跑（接口 3 轮 + UI）
npm run test:roleagent

# 分开跑
npm run test:roles        # 接口层：3 轮 × 5 岗位全流程
npm run test:ui           # UI 层：真实浏览器（本机 Edge）

# 自定义轮数
node tests/role-agent/run.js --rounds 5
```

## 前置条件

1. 本地服务在跑：`node src/app.js`（127.0.0.1:3000，ALLOW_DEV_LOGIN=true）
2. UI 层另需两个静态托管（测试期间手动起，跑完可关）：

```bash
# 小程序 H5（先 npm run build:h5）—— 必须用 no-store 的静态服务，
# python http.server 不发 Cache-Control，浏览器会拿缓存的旧 JS（踩过坑）
cd server && node tests/role-agent/static-serve.js ../miniprogram/dist/build/h5 5174

# 后台本地版（先 npm run build:local，产物 dist-local 指向 127.0.0.1）
cd server && node tests/role-agent/static-serve.js ../admin/dist-local 5176 admin
```

3. UI 层依赖本机 Edge + 托管工作区的 @playwright/cli（已装，ui-check.js 内置路径回退）。

## 覆盖什么

**接口层（run.js，每轮新建独立测试物料，互不影响）：**

| 模块 | 断言 |
|---|---|
| 权限门 P0 | 老板不能造/剥夺/禁用管理员；唯一管理员不可降级；各岗位越权全 403 且留痕 |
| 出入库 | 单价 0/负数拒；四态流转（pending→picking→receiving→completed）；跨仓提交拒；改价；取消 |
| 撤销规则 | 待确认可撤、待拣货可撤、**待收货不可撤**（用户定的规则）；撤别人的单 403 |
| 采购 | 建单→领取→录入→收料自动入库；**退回重采**全流程；取消任务；重复领取幂等；加权均价精确核对 |
| 盘点 | 建单→录入→待审禁改→审批只认明确 true/false→库存调到实盘数；取消盘点；老板收到待审消息 |
| 主数据 | 供应商/仓库增查删权限；物料编辑（单位/预警线）；管理员删物料；分类接口 |
| 用户 | 建号→登录→改资料→重置密码→本人改密→禁用后拒登；待审用户审核通过全链路 |
| 消息 | 9 类通知必达；未读数/单条已读/全部已读 |
| 统计 | 趋势/排行/绩效/流水/订单流水各角色可见性 |
| 两端一致 | 老板看板 = 后台看板（5 个核心字段）；预警四口径一致；零库存不随分页变 |
| 对账 | 账面 = 流水累加 = 接口读数；金额两位小数；最终库存精确到个位 |

**误操作包（mistakes.js，模拟真人会犯的错）：**

| 误操作 | 期望行为 |
|---|---|
| 网络卡了连点提交（出入库） | 幂等键去重，**只落一张单** |
| 数量 0 / 负数 / 小数 / 文字 | 400 拒绝 |
| 单价填 0 改价 | 400 拒绝（成本失真） |
| 不存在的物料 / 空明细 | 404 / 400 拒绝 |
| 超额领料（比库存多100） | 400 库存不足 |
| 重复收货 / 重复拣货 / 重复审批 | 幂等提示「已办过」，**不重复扣库存、不重复调账** |
| 重复领取采购任务 | 幂等提示「你已经领取过」（设计如此） |
| 盘点录入不存在的物料行 | 400 明确报错，不静默吃掉 |
| 物料档案直改库存 | 400 封死（库存只能走单据/盘点） |
| 未登录 / 伪造 token / 不存在的模块 | 401 / 404，且留痕 |

**UI 层（ui-check.js，真实 Edge 无头）：**

- 后台 10 个路由逐个渲染 + 无控制台报错 + 看板数字与接口一致
- 小程序 H5：老板/仓管两个身份登录 + 首页/消息中心/盘点列表渲染

## 报告

`tests/role-agent/results/RA-report-*.md`（接口）/ `RA-ui-report-*.md`（UI），
控制台同时打印汇总。断言失败带「修前会错 / 修后该对」的判据描述。

## 测试数据

每轮产生：2 个物料（`[RA-R<轮>]` 前缀 + RUN 后缀）、约 6 张单据、1 张盘点单、若干审计日志。
全部带标记可清理；软删物料不影响对账（对账按物料维度）。
