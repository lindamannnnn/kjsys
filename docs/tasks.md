## 第 2 周：基础设施（2026-10-05 ~ 2026-10-11）

> ⚠️ **架构已变更**（2026-09-29）：后端由微信云开发改为**自建服务器（Node + Express + MySQL，Docker 化）**，
> 下表已按新架构重写。详见 [BACKEND-PLAN.md](./BACKEND-PLAN.md)。
>
> **术语对应**：下文任务中出现的「XX 云函数」一律理解为「后端模块 XX 的对应接口」；
> 「上传到云存储」理解为「保存到服务器文件目录」；「配置云开发环境」已被上方 Docker 环境替代。

### 目标
- 本地 Docker 环境一键起（MySQL + 接口服务），建表完成，后端模块骨架就绪

### 任务分解

#### 本地开发环境（Docker）

- [ ] 编写 `docker-compose.yml`（api + mysql 两个服务）
- [ ] 编写 `server/Dockerfile`
- [ ] 配置 `.env`（数据库密码、JWT 密钥、微信 AppID/AppSecret、接口域名）
- [ ] `docker compose up -d` 起 MySQL 与 api，健康检查通过
- [ ] 确认本地容器可正常连接（`/api/health` 返回正常）

#### 数据库建表（11 张表）

- [ ] `users`（含 username / password_hash 支持后台登录）
- [ ] `materials`（含 warehouse_id 多仓库，UNIQUE(name, spec, warehouse_id)）
- [ ] `warehouses`（配件仓 / 成品仓）
- [ ] `outbound_orders`（含 client_request_id 唯一索引 + warehouse_id + 确认字段）
- [ ] `inbound_orders`（同上）
- [ ] `stock_checks`（盘点主表）
- [ ] `stock_check_items`（盘点明细，由原内嵌数组拆出）
- [ ] `stock_logs`（库存流水，索引 material_id + created_at）
- [ ] `suppliers`
- [ ] `operation_logs`
- [ ] `settings`
- [ ] 初始化基础数据（两个仓库、settings、首个 admin 账号）
- [ ] 建全表索引并用 `EXPLAIN` 抽查关键查询

#### 后端模块骨架

- [ ] Express 入口 `app.js`（路由分发 + 统一响应 + 错误处理）
- [ ] `middleware/auth.js`（JWT 校验）
- [ ] `middleware/permission.js`（角色权限 + 仓库数据权限）
- [ ] `middleware/idempotent.js`（幂等拦截）
- [ ] `services/wechat.js`（code2session 封装）
- [ ] `services/stock.js`（**库存变更唯一出口**：事务 + 行锁 + 流水）
- [ ] `services/orderNo.js`（单号生成）
- [ ] `modules/auth.js`（login/register/updateProfile/getUserInfo）
- [ ] `modules/material.js`（list/detail/upsert/import/delete）
- [ ] `modules/outbound.js`（submit/list/detail/cancel/confirm/reject）
- [ ] `modules/inbound.js`（submit/list/detail/updatePrice/confirm）
- [ ] `modules/check.js`（create/list/detail/submit/review）
- [ ] `modules/stats.js`（overview/trend/stockList/orderFlow/warning/stockFlow）
- [ ] `modules/user.js`（list/approve/disable/enable/updateRole）
- [ ] `jobs/warning.js` + `jobs/backup.js`（node-cron 定时任务）

#### 前端传输层改造

- [ ] 重写 `miniprogram/src/utils/cloud.js`（callFunction → wx.request，**保持函数签名不变**）
- [ ] 修改 `admin/src/api/index.js`（API_BASE + JWT 携带）
- [ ] 小程序本地开发配置（勾选"不校验合法域名"，接口地址一处可配）

#### 交付物
- [ ] 本地 `docker compose up -d` 一键起全套
- [ ] 11 张表创建完成，索引就绪
- [ ] `/api/health` 与至少一个业务接口本地可通
