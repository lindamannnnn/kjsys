# 提审录屏分镜（照着走，一次过）

> 用途：微信小程序提审时的**功能演示录屏**（附件）。
> 为什么非要这个：审核员用他自己的微信登录后，只会得到「待分配岗位」的空账号，
> **什么功能都看不到** → 很容易被判「功能不完整」驳回。附一段录屏，等于替审核员
> 把系统跑一遍给他看。
>
> 目标：**1 分 30 秒 ~ 2 分钟**，全程**真机录屏**（不要用开发者工具录）。
>
> 📢 **要逐字口播稿 + 每个镜头的操作细节 → 看《`docs/提审录屏脚本.md`》**
> （本份是设备/机位/压缩的操作手册；脚本那份是照着念的稿子）。
> ⛔ **脚本开头有「开录前必做」**：现在库存全是 0，**不先入库，领料提交会直接报「库存不足」**。

## 〇、用什么录？手机还是电脑？（先看这一节）

### 结论：**手机录。电脑只做两件辅助的事。**

| 设备 | 干什么 |
|---|---|
| **手机**（真机） | ✅ **录屏用它** —— 全程在手机上操作、手机上录 |
| 电脑 | ① 用开发者工具**生成二维码**（让手机能打开小程序）<br>②（可选）最后把视频压到 10MB 以内 |

**为什么必须手机录**：审核员看的是真机体验。用开发者工具录屏，一眼就能看出是模拟器——
界面上有工具栏、没有真实状态栏、微信授权是模拟的，说服力大打折扣。而且我们用到的
微信登录是真机能力，模拟器里演示不出真实链路。宁可画面糙一点，也要真机。

### 手机上怎么打开这个还没上架的小程序？（两条路，走路 A）

**路 A（推荐，最快，现在就能用）—— 开发者工具「预览」**

- [ ] 电脑上打开微信开发者工具 → 打开目录 `G:\sl\shenglong-erp\miniprogram`
      （这个目录的配置已指向构建好的正式包，工具会自动读到最新代码）
- [ ] 点工具栏上的「**预览**」按钮

### 手机自带录屏怎么开

| 手机 | 怎么开 |
|---|---|
| **iPhone** | 先在 `设置 → 控制中心` 里添加「**屏幕录制**」→ 之后从右上角下拉控制中心 → 点那个**圆圈点**图标开始。<br>⚠️ **要录旁白的话，长按这个图标**，会弹出「麦克风」开关，**打开它**（iOS 默认不录声音） |
| **安卓**（华为/荣耀/小米/OPPO/vivo/三星） | 从屏幕**顶部下拉**出控制中心 → 找「**屏幕录制**」→ 点开始。<br>开始前若弹窗问「声音来源」，选 **麦克风**（或「媒体声音+麦克风」），否则旁白录不进去。<br>找不到就在设置里搜「录屏」 |

#### 📱 iPhone 详细步骤（按顺序点，30 秒搞定）

**第 1 次用要先添加按钮**（只需做一次）：

- [ ] `设置` → `控制中心` → 在「**更多控制**」里找到「**屏幕录制**」
- [ ] 点它左边的 **绿色 ➕**，把它加到「已包含的控制」里

**开录**：

- [ ] 从屏幕**右上角向下滑**，呼出控制中心
      （⚠️ 带 Home 键的老 iPhone 是**从底部向上滑**）
- [ ] **长按**那个「**◎**」圆圈图标（就是刚加进来那个）—— 会弹出菜单
- [ ] 菜单里点「**麦克风**」把它**点亮**（变成红色/高亮）→ **这一步决定旁白能不能录进去，最关键**
- [ ] 点「**开始录制**」→ 3 秒倒计时后开始
- [ ] 向上滑一下（或点空白处）**收起控制中心**，别让它留在画面里
- [ ] 回微信打开小程序，按下面第二节分镜开始操作

**停止**：

- [ ] 点屏幕**左上角的红色小胶囊**（状态栏那个红点/红条）→ 弹出「停止」→ 点它
- [ ] （也可以重新呼出控制中心，再点一次那个圆圈图标）

**录完去哪找**：

- [ ] `照片` App → 底部「**相簿**」→ 找「**屏幕录制**」这个相簿
      （iOS 会自动归档；找不到就看「最近项目」里最新那条）

**四个 iPhone 特有的坑**：

- ⚠️ **录屏不能暂停**，只能一次录到底 —— 中间点错了就重录；或者事后在 `照片 → 编辑 → 裁剪` 把错的那段剪掉
- ⚠️ **来电话 / 微信语音会直接掐断录制** —— 录之前跟身边人说一声别打给你
- ⚠️ **文件不小**：1 分半大约 **100~200MB**，先确认手机空间够
- ⚠️ **不要边录边开控制中心面版**，那样会把控制中心录进画面（收起来再操作）

---

**录制前的三下**：

- [ ] **竖屏**录，锁住方向（别开着自动旋转，中途转了很难看）
- [ ] 开**勿扰模式**，清掉通知（弹微信消息进画面很减分）
- [ ] 屏幕亮度调高一点（录出来偏暗审核员看不清）

## 一、录之前的准备（5 分钟）

- [ ] **一台手机**，微信已登录（录屏用这台）
- [ ] **提前登录一次再退出** —— 让手机记住微信授权，录屏时不会卡在授权页
- [ ] **后台准备好演示账号**：给这个账号同时分配
      **「车间领料」+「成品仓管」**两个岗位（后台角色可多选；这样一台手机能演完整条链）
      —— 如果后台不方便给一个号配两个岗位，就**分两段录**（领料一段、仓管一段），
      最后把两段拼起来，或干脆按下面第七步的简化版只录到「提交成功」
- [ ] **后台先备好一条演示物料**（要有库存，例如「螺丝 M6」），别用空库存的料
- [ ] 把单据清干净（录屏里出现的待办单越少越清爽）
- [ ] 手机开**勿扰模式**（录屏中途弹微信通知会很难看）
- [ ] 手机**电量 > 50%**，关掉自动亮度
- [ ] 想好要不要**旁白**：建议要，全程轻声讲，见下面「旁白参考」。
      （不配字幕、不加背景音乐 —— 加了反而像宣传片，真实感反而下降）

> ⚠️ 不用担心把「测试账号一键登录」录进去 —— 那段代码只存在于开发构建，
> 正式包里 `DEV_MODE=false` 已彻底关闭，审核员和你的正式包都看不到它。

## 四、录制技巧（决定审核员体验）

- **手指慢一点**，每步操作完**停 1 秒**再点下一处 —— 审核员要看清。
- 页面上有**加载中**的地方，多停 1 秒，别切太快让人以为是空的。
- **别晃手机**，拿稳或用支架。
- 一段录不完就分段录，最后拼；**别中途退出重进**，剪掉会显得不连贯。
- 录完自己**从头看一遍**，确认没有黑屏、没有弹窗、没有跳到别的 App。

## 五、录完之后：压缩 + 传到电脑（最容易卡住的一步）

### 5.1 先压体积

微信提审附件对**视频体积有上限**（通常 10MB 左右）。手机录 2 分钟原片常有几十上百 MB，
**直接上传会被拒**。上传前先压缩：

- 目标：**720p / 8MB 以内 / mp4**
- **iPhone 上怎么压（三选一，从上往下试）**：
  1. **先直接试传** —— 如果录得短（1 分钟内、画面不复杂），有时原片就不到 10MB，能传就不用压
  2. **剪映**（推荐，免费）：App Store 装「剪映」→ 导入录屏 → 直接点导出 →
     分辨率选 **720p**、帧率 **30**、码率选低档 → 导出 mp4。1 分半的片子一般能压到 10MB 以内
  3. **微信自带压缩**：手机微信把视频发给「文件传输助手」→
     ⚠️ **发送时不要勾「原视频」** → 微信会自动压 → 在**电脑微信**上另存下来
- **电脑端**：用任意转码工具把码率压到 1Mbps 左右即可

### 5.2 再从手机传到电脑

提审是在**电脑网页**上操作（公众平台），视频得先落到电脑上。三选一：

| 方式 | 怎么做 | 备注 |
|---|---|---|
| **微信文件传输助手**（最省事） | 手机微信 → 搜「文件传输助手」→ 发视频 → 电脑微信里另存到本地 | 视频稍大会被压缩（对我们反而有利）；也可能提示超限，那就用下一种 |
| **数据线** | 手机连电脑 → 找到「录屏」相册目录 → 复制出来 | 画质无损，安卓/iPhone 都行 |
| **云盘** | 上传到网盘 / 手机厂商云 → 电脑下载 | 慢一点，但什么都能传 |

> 💡 小技巧：如果录屏原片就很小（1 分钟内、画面不复杂），也可能**直接小于 10MB**，
> 那就先试传，传得上去就不用压缩了。

## 七、如果录不了完整链路（简化版）

如果后台不方便给一个账号配多个岗位、也不方便用两台手机：

**至少录到第 7 步（提交出库成功）**，并把第 6 步的入口卡片每个都点开看一眼。

仓管确认那一段能加上最好，加不上不要紧。
