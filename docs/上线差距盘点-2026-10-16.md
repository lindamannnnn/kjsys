## 四、⚠️ 本次新发现的风险（重点看这两个）

### 风险 1：生产管理员密码泄漏到 public 仓库（高危）

`git grep` 查到两个文件**明文写着生产管理员账号密码**：

```
docs/audit-raw-老板王总.md
server/tests/audit-GUIDE.md
```

仓库是 **public**（`github.com:lindamannnnn/kjsys`），且**已实测该密码当前有效**（线上 `adminLogin` 返回「登录成功」）。
=> 任何人看到仓库就能登进生产后台。**必须重置密码**（仅删文件不够，git 历史里还有）。

### 风险 2：后端 3000 端口对公网开放

`ss` 显示 `0.0.0.0:3000`，本机实测可直连返回 200。叠加 `ALLOW_DEV_LOGIN=true` 后，
等于把「任意身份登录」的接口挂在公网明文 HTTP 上。应收敛为 `127.0.0.1`。
