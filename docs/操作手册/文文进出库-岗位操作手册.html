一眼看懂：货是怎么走的

下面两条线是全系统的主干。看懂这两张图，后面各章都只是细节。

一、领料（从仓库把货领到车间）

领料员手机提交领料单
→
仓管确认这张单
→
仓管去拣货，点「拣货完成」
→
领料员点「确认收货」
此时才扣库存
最容易搞错的一点 领料单「提交」时不扣库存。要等货真正领到手、点「确认收货」那一秒，库存才减。 所以单据状态还停在「待确认」的时候，仓库里的数是不动的。

二、采购（从外面把货买回来）

仓管发起采购任务
→
采购员领取任务、去买
→
采购员回来填单价、单号、拍照
→
仓管逐项「到货入库」
此时才加库存
入库反过来：提交就加库存 仓管在「入库登记」里点提交，库存立刻加，不用等谁确认。所以入库的数量和单价一定要当场核对清楚。
CHAPTER 00

开始之前：两个入口、三件必知

0.1 系统有两个入口，用哪个？

入口怎么打开适合干什么
手机小程序
「文文进出库」		 微信 → 搜索小程序「文文进出库」→ 点进去；或用微信扫管理员发的码 仓库里跑动时用：领料、入库登记、拣货确认、盘点录入、拍照上传。站在货架前就用这个。
电脑后台
网页		 电脑浏览器输入 https://sl.ekkosys.cn/admin/ 坐着办公时用：批量看单、导出表格、改物料资料、审批、查台账、看统计。对账和批量操作就用这个。
两边是同一份数据 手机上提交的单据，电脑上刷新就能看到；电脑上改的物料，手机上马上也是新的。不存在「两边对不上」这回事，如果看到不一样，多半是手机页面没刷新（下拉一下就刷新了）。

0.2 怎么登录

手机（微信小程序）

  1. 微信搜索「文文进出库」，或在微信里扫管理员给的二维码。
  2. 点「微信一键登录」，微信会问你要不要授权，点允许。
  3. 第一次登录会停在「等待管理员审批」。这是正常的——你的身份还没定，需要管理员在电脑后台把「岗位」和「能管哪个仓」配给你。
  4. 管理员配完后，退出小程序重新进一次，首页就会出现你的功能卡片。

电脑（后台网页）

  1. 浏览器输入 https://sl.ekkosys.cn/admin/。
  2. 输入管理员发给你的账号和密码。账号规则一般是 sl + 岗位拼音，例如仓管是 slpeijian。
  3. 第一次登录如果要求改密码，改完记住新的，别忘了（管理员也看不到你的密码，忘了只能重置）。
  4. 登录后看左上角：会写「后台管理系统 / 配件仓后台 / 成品仓后台 / 采购后台 / 经营看板」，不同岗位显示不同，这是正常现象。
手机登录和电脑登录是两套身份吗？ 不是同一把钥匙。手机上你用的是微信；电脑上用的是账号密码。 有些老员工只有微信登录（扫过码注册的），没有账号密码，所以电脑登不进去——需要管理员在「用户管理」里给他补一个账号密码。

0.3 三件必知

① 首页的卡片，就是你能干的事

不同岗位首页卡片不一样，这是按岗位配好的，不是坏了。你看不到「入库登记」，说明入库不该你做；你看不到「成品仓出库」，同理。找不到功能先问自己：这是不是我的活？

② 消息中心会主动告诉你该动手了

手机上首页下方有「消息」入口，后台左边有「消息中心」，有红点就是有活等着你。常见的几种：

  • 仓管：「有新的领料单待确认」「盘点已提交待审核」「采购到货待收」
  • 领料员：「你的领料单已拣货，请确认收货」「你的单被驳回」
  • 采购员：「有新采购任务可以领」
  • 厂长 / 管理员：「有盘点单等你审核」

③ 金额不是所有人都能看

仓管员、领料员默认看不到金额 这是故意设的，不是系统错了。仓管只看数量、单位，页面上的单价、金额栏是空的或者不显示； 领料员同样看不到金额。老板、厂长、采购员、管理员能看到金额和成本。 如果一个仓管同时被分配了「厂长」身份，那就按能看的算。
CHAPTER 01

领料员（车间）

你是谁
车间要料的人
主要用
手机小程序
手机卡片
领料出库、报废申请、库存流水
电脑后台
只有消息中心
一句话说清你的活 车间缺什么，你用手机提单领；仓库把货拣好了，你点「确认收货」。你点的这一下，才算真正把货领走。

1.1 手机上你有 4 个入口

卡片干什么什么时候用
领料出库提领料单（要多少个、什么货）车间缺料，需要仓库发货时
报废申请东西坏了、废了，申请报废，必须拍照 + 写原因物料损坏、做废了、不能再用
库存流水查每一笔出入库记录想确认自己的单走到哪一步、领过什么
消息系统通知看到红点就点开，别让它一直亮着

电脑后台你只有「消息中心」一项。领料、报废都是手机上做的事，后台没开这些入口，不用去后台找。

1.2 领料出库：完整 6 步

  1. 点首页「领料出库」。
  2. 找货。顶上可以打字搜（输名称或规格，比如「火花塞」「M14」），也可以点右边的相机图标扫码。 下面还能按仓库、按分类（细分类）筛，货多的时候先筛一下快。
  3. 加数量。点中物料后填你要的数量，再点「加入清单」。要几样就重复几次。
  4. 选出库类型。车间自己用选「领用」；机器坏了要修选「维修」。 （如果是厂长发起成品仓出库，类型是「销售」或「领用」，那是另一条线，你不用管。）
  5. 填写用途/备注（选填）。建议写一句，比如「3 号线换件」，被驳回时也好对账。
  6. 点「提交出库（N 项）」。提交成功就等仓库确认。
提交的时候库存还不减 这时候单子的状态是「待确认」。仓库那边确认、拣货，都还没有真正出库。别急着跟仓库说「我已经领了」。

1.3 仓库拣完货，你要点「确认收货」

仓库拣好货以后，你的首页最上面会出现一条提示：「你有 N 张领料单待收货」，下面写着单号和仓库名。

  1. 点这条提示（或进「库存流水」找到那张单）。
  2. 核对：单上的物料、数量，和你手上拿到的是否一致。
  3. 一致就点「确认收货」。这一下库存才真正减掉。
  4. 不一致（少给了、给错了）——先别点，直接找仓管当面核，让他改。
如果你一直不点「确认收货」 单子会一直停在「待收货」，库存不会减，账面数字比实际多。仓管那边可以在你同意后代你点「代确认收货」。 不要让它一直挂着，当天的事当天结。

1.4 单子被驳回了怎么办

仓库如果觉得这张单有问题（数量不对、重复提交、料号选错），会驳回并写原因。你首页会出现一条橙色提醒：「你有 N 张出库单被驳回」。

  1. 点开提醒，看驳回原因。
  2. 按原因改：数量错了就重新提一张正确的；选错料就重新选。被驳回的单不用管它，它会停在「已驳回」不再动。
  3. 如果觉得驳回没道理，直接找仓管沟通，别自己反复提交。

1.5 报废申请（单独一个入口，别混在领料里）

东西坏了要报废，和「领料」是两码事，所以要单独点「报废申请」。

  1. 点首页「报废申请」。
  2. 选物料、填报废数量。
  3. 拍照：把坏掉的实物拍清楚，这是必填项，不拍交不了。
  4. 写原因：怎么坏的、谁弄坏的、发生在哪。也必填。
  5. 提交，然后通知仓管去处理。
为什么非要拍照报废是「东西没了但要有个说法」，照片和原因是唯一凭据，也防止拿报废掩盖少货。省不掉，拍清楚。

仓管员（配件仓 / 成品仓）

你是谁
管仓库的人
主要用
手机为主 + 电脑为辅
手机卡片
入库登记、仓管工作台、库存盘点、库存流水、发起采购（配件仓）
电脑后台
6～7 项菜单
一句话说清你的活 进来的货要登记（提交就加库存）；要出去的单子要确认、要拣货；定期盘一次账； 月底跟老板对得上数。你是全系统最忙、也最关键的一个岗位。
配件仓管和成品仓管不一样 你被分配到哪个仓，就只能看哪个仓的货： 配件仓管管零件、辅料，能发起采购（要买配件），会有「采购任务」这张卡； 成品仓管管做好的成品，没有采购任务卡（成品不用买），但后台多了「成品仓出库」一个菜单。 两边互相看不到对方的货，这是故意的，防止串仓。

2.1 手机上你有 6 个入口

卡片干什么谁有
入库登记货进仓时登记数量、单价、供应商。提交即入账两个仓管都有
仓管工作台待办总入口：确认单据、拣货、查本仓库存、全部流水两个仓管都有
库存盘点建盘点任务、录实际数量、提交审核两个仓管都有
库存流水本仓每一笔出入库两个仓管都有
发起采购发布采购任务给采购员，或自己领了去买只有配件仓管
消息待确认、待收货、待审核提醒两个仓管都有

2.2 入库登记（最常用，也最容易出错）

使用场景：供应商送货到、车间退回好料、成品做出来了要入成品仓。

  1. 点首页「入库登记」。
  2. 选仓库（如果你只管一个仓，会自动是那个仓）。
  3. 找货：搜名称或规格，扫码也行。
  4. 如果系统里没有这个物料：点「新建物料」，填名称（必填）、单位、预警库存、大类（必填）、规格、细分类、物料编号、拍张照。建完就能直接选来用。 第一次进的新货一定要建档，不然以后没法盘、没法查。
  5. 填数量（入库数量）。
  6. 填单价（元）。这一栏决定成本，看不懂就找采购员要实际单价，别随手填 0。填 0 会让成本被永久拉低。
  7. 看小计对不对（数量 × 单价，系统自动算）。
  8. 供应商：可以直接手打，也可以点右上角从供应商档案里选。
  9. 备注：建议写来源，例如「XX 供应商送货」「3 号线退料」。
  10. 点「提交入库」。
入库是「提交即入账」，没有后悔药 点了提交，库存立刻加，不会等谁审批。所以： 数量先数清楚，单价先问清楚，再点提交。 填错了怎么办？如果是数量多填了：在「入库单」里找到这张单做「撤销」（只有未确认的能撤）。已经用掉的，只能通过盘点调回来。

2.3 仓管工作台：4 个数字是什么意思

数字意思你要做什么
待确认有人刚提了单，等你点头点进去，核对后点「确认这张单」
待拣货你已经确认了，但货还没拣出来去货架拣货，拣完点「拣货完成」
待收货货拣好了，等领料员来拿等对方点确认收货；对方不方便你可以点「代确认收货」
今日单据今天一共处理了多少单看工作量，不用操作

待办单据的三种操作，别点错

  1. 确认这张单——单子是「待确认」时出现。确认前先看物料、数量对不对，不对就驳回（在明细里能找到驳回，需要写原因）。
  2. 拣货完成——单子是「待拣货」时出现。你手上货已经点齐了再点。
  3. 代确认收货——单子是「待收货」时出现。只在领料员当场拿到货、但他不会用手机时用，用完要跟他说一声。
出库的库存，是「确认收货」那一刻才减 你确认单据、拣货完成，库存都还不动。这是设计——防止单子开了货没拿走，账面数量先掉下去，盘点又对不上。

2.4 采购收料：采购员买回来的货怎么进仓

采购员在外面买完，会在任务里填好单价、单号、拍好小票。货送到你手上时：

  1. 手机上点「采购任务」（在工作台里，或首页「发起采购」进去）。
  2. 找到状态是「待收料」的那张，点开详情。
  3. 对着货逐项点「到货入库」，填实际到货数量。 到货可能分批，比如要 100 个先到 60 个，就先收 60，剩下 40 下次到再收。每收一次，库存就加一次。
  4. 全部收齐后（按钮会从「还有 N 项未到齐」变成「完成收货」），点「完成收货」把任务办结。
  5. 货不对（数量少、型号错、质量差）：点「退回给采购员」，并写清原因。
采购单不会自动加库存 采购员点「提交采购信息」，库存一点都不会加——那只是记录「买到了、多少钱」。 真正进仓要靠你这里点「到货入库」。忘了收，账面就是缺货。

2.5 库存盘点：怎么盘、盘完谁审

什么时候盘：月底、老板要求、或者发现账面对不上。

  1. 点首页「库存盘点」→ 右下角「＋ 新建盘点任务」。
  2. 选盘点类型（全盘 / 抽盘）、盘点仓库。
  3. 选盘点范围：全盘就是整个仓都盘；只盘几样就点「选择物料」勾出来。
  4. 建好后点开这张盘点单，进「盘点录入」。
  5. 每样货都有「账面数」和「实际数量」两栏。你只填「实际数量」——去货架数，数多少填多少。
  6. 偷懒小技巧：大部分货都对得上时，先点「其余按账面数填」，再单独改有差异的那几行。
  7. 没盘到的可以留空（留空的不会被提交，可以下次补盘）。
  8. 看着「差异」那一列（正数是多出来，负数是少了），确认没问题后点提交。
盘点不是你说了算 提交后状态是「待审核」。要等厂长或管理员在电脑后台点「审核通过并调账」，账面数才会真的改成你数的数。 他们也可能「退回重盘」，让你重新数一遍。 所以盘完要提醒他们去审，不然白盘了。

2.6 电脑后台：你能看到这些菜单

菜单能干什么配件仓管成品仓管
数据看板本仓库存概览、今日单据有有
统计分析 › 出入库统计按时间看进出数量和金额有有

物料管理 › 成品仓物料查/改成品资料、看库存、导出表格—有
单据管理 › 出库单查所有领料/销售单，看状态有有
单据管理 › 入库单查所有入库单，可以撤销没确认的有有
单据管理 › 新建入库单在电脑上批量录入库（货多时比手机快）有有

2.7 电脑上怎么新建入库单（货多的时候用）

  1. 左边点「单据管理 › 新建入库单」。
  2. 选仓库、选供应商（可以手打）、填单号（没单号就留空或问管理员）。
  3. 一行一行加物料：选物料、填数量、填单价，加几行都行，最后看合计金额。
  4. 保存 → 提交。同样是提交即入账。

2.8 仓管的三条纪律

这三条违反一次，账就要花好几天修

一、单子别压着。每天下班前把「待确认」「待拣货」清到 0。压着会让库存一直不准，月底盘点全是差异，最后还是你自己加班。

二、单价问清楚，不要填 0。入库单价是成本的唯一来源。填了 0 会把成本拉低，老板看到的毛利就是假的，而且改不回来。

三、别自己改库存数字。物料资料能改名称、规格、单位，但数量不是直接填的。对不上就走盘点，让厂长/管理员审核后调账，这样才有记录可查。

3.1 采购任务：完整流程

  1. 手机点「采购任务」（登录后默认就落在这个页面，因为这是你的主场）。
  2. 看「待领取」这一栏。卡片右上角有数字，就是有新任务。
  3. 点开看明细：要买什么、多少、哪个仓要的、有没有参考价。
  4. 点「领取任务」。领了之后单子归你，状态变「采购中」，别人就抢不走了。
  5. 去买货。
  6. 买回来后在详情页点「展开录入表单」，每样货填一行：实际单价、实际数量、发票号/单据号。
  7. 上传小票或发票照片——点上传框，拍照上传。这是报销和对账的凭据，别跳过。
  8. 点「提交采购信息」。状态变「待收料」。
  9. 把货交给仓管。仓管收完货，状态变「已入库」，这单就结束了。
你提交以后，库存是 0 增长 很多人以为「我买了 100 个，系统里就有 100 个了」——没有。你提交的只是「买了、多少钱」。 库存要等仓管点「到货入库」才加。所以货一定要交到仓管手上，别往仓库门口一放就走。

状态意思该谁动手
待领取仓管刚发的任务，还没人接你——去领取
采购中你已经领取，正在买你——买完填信息
待收料你已提交采购信息，货还没到仓仓管——收料入库
收货中仓管在收，可能分批到仓管
已入库全部收完，办结了—（结束了）
已取消仓管取消了这张任务—（不用管）

3.3 被退回给采购员怎么办

仓管发现货不对（数量少、型号错、质量差），会在任务里点「退回给采购员」。你会收到消息。

  1. 进「采购任务」找到这张单，看退回原因。
  2. 补货 / 换货 / 找供应商。
  3. 回来重新展开录入表单，改数量和单价，重新提交。

4.2 发起成品仓出库：完整流程

客户要货、或者成品要调到别处，由你发起。

  1. 点首页「成品仓出库」（橙色那张卡）。
  2. 仓库已经锁死在成品仓，不用选，也选不了——这是为了防止发错仓。
  3. 搜物料、加数量。
  4. 选出库类型：卖出去选「销售」，内部用选「领用」。
  5. 填备注（比如客户名、订单号），点提交。
  6. 提交后由成品仓管拣货。拣完你会收到消息。
  7. 进消息或单据详情，点「确认收货」——这一下才扣库存。
你负责开单和确认，不负责搬货 开单、确认是你的；拣货是仓管的。两边配合，单子才走得完。 你一直不确认，库存就一直不减，月底账面会偏大。

4.3 审核盘点（你最重要的一个动作）

仓管盘完提交后，状态是「待审核」，会推消息给你和管理员。

  1. 电脑后台左边点「盘点管理」。
  2. 筛选状态「待审核」，点开要看的那张。
  3. 看明细：每样货的账面数、实盘数、差异。差异大的几项要问清楚原因（是漏记入库？还是丢了？）。
  4. 确认没问题 → 点「审核通过并调账」。点完这一下，账面数才改成实盘数。
  5. 有问题 → 点「退回重盘」，写原因，让仓管重数。
「审核通过并调账」是不可逆的 点下去库存就按实盘数改了。所以别顺手点——先看差异清单，特别是负数（少了）的项，逐条问过再点。

5.3 新员工来了，怎么给他开账号（最常用）

  1. 让员工先用微信扫码登录小程序一次，他会停在「等待审批」。
  2. 你打开电脑后台「用户管理」，会看到一条待审批记录（有微信头像、昵称）。
  3. 点开他，设置：真实姓名、岗位（可多选，比如同时是厂长和仓管）、能管哪个仓。
  4. 保存。他退出小程序再进，首页就有对应的卡片了。

6.2 首次上线：期初建账（只在刚上线时用一次）

系统刚上线时，仓库里本来就有一批货，但系统里是 0。这些「老库存」要填进去，叫期初建账。

  1. 「系统设置」→「期初建账」标签页 → 打开开关。

  1. 「用户管理」找到这个人。

  3. 提醒他登录后马上自己改掉。

手机微信登录的人不需要密码，他们忘不了；只有用电脑后台的人才需要账号密码。

CHAPTER 07

常见问题 15 问

1. 登录后显示「等待管理员审批」，什么都点不了

正常。你的微信已经注册上了，但岗位还没配。找管理员在电脑「用户管理」里给你设岗位和仓库，然后你退出小程序重新进一次。

2. 我手机上怎么没有「入库登记」？

说明你的岗位不是仓管。首页卡片是按岗位发的，不是坏了。真需要这个功能，让管理员给你加岗位。

3. 我明明是仓管，为什么看不到金额？

故意的。纯仓管只看数量、不看金额和成本。老板、厂长、采购员、管理员能看。要能看金额，得由管理员给你加相应岗位。

4. 电脑后台登不进去，说我账号密码错

先确认三件事：账号是不是管理员给的那个（注意大小写，一般全小写）；密码有没有改过；是不是把微信登录当成后台登录了。都不对就找管理员重置。

5. 手机上做的单，电脑上没看到

电脑页面没刷新。按 F5 刷新一下，或点一下页面上「搜索」按钮重新查。数据是同一份，不会丢。

6. 我的领料单交了很久，仓库一直没动

状态应该是「待确认」。直接找仓管，让他点「确认这张单」。

7. 仓库说已经拣好了，我这边库存怎么还没减

因为你还没点「确认收货」。首页会有提示条「你有 N 张领料单待收货」，点进去确认。这一步才扣库存。

8. 单子填错了数量，能改吗

单子现在的状态怎么改
待确认让仓管驳回，你重新提一张正确的
待拣货 / 待收货找仓管，让他驳回或作废
已收货（已扣库存）只有管理员能作废。库存已经动了，作废后会回补
入库单（已入账）找仓管「撤销」；已经用掉的只能靠盘点调回来

9. 我在入库时单价填了 0，会怎样

这批货的成本会被算成 0，而且改不回来（成本是用加权平均算的，0 会永久把平均值拉低）。发现填错了马上找管理员，看能不能作废重开。

10. 库存数量和实际对不上

不要直接改数字（也改不了）。正确做法：仓管发起盘点，数出实际数量提交，厂长或管理员审核通过后，账面自动改成实盘数，而且有完整记录。

11. 采购员说货买了，为什么库存还是 0

采购单不会自动加库存。要仓管在「采购任务 → 详情」里逐项点「到货入库」，库存才加。货要交到仓管手上。

12. 盘点提交了，什么时候生效

要等厂长或管理员审。他们在电脑「盘点管理」里点「审核通过并调账」之后才生效。提醒他们去审。

13. 报废为什么非要拍照

报废是「东西没了但要有个说法」。照片和原因是唯一凭据，也防止用报废掩盖少货。这条省不掉。

14. 手机上没有「新建物料」，但来了个新货怎么办

进「入库登记」，搜不到这个物料时点「新建物料」，填名称、大类（这两个必填），其他能填就填，然后就能直接入库了。

15. 我想知道谁改过一条数据

老板和管理员可以在电脑「操作日志」里查：时间、谁、做了什么操作、改了什么。仓管和采购看不到这一页，需要的话请他们帮查。

手册里没写到的，找谁

遇到的情况先找谁
卡片 / 菜单看不到、账号密码忘了、新员工要开通管理员（用户管理里改）
单据卡住不动（状态一直不变）看附录的状态表，找该谁动手的那个人
库存数量和实际对不上先找仓管核对，确认要改就发起盘点
金额、单价填错了管理员（能不能改要看单子状态，见问题 8）
页面打不开、一直转圈、报红字先刷新一次；还不行联系开发，把截图发过去
两条不要做 一、不要自己在系统里试来试去想「试出正确做法」——单据一旦提交就会动库存，试错成本很高。
二、不要让别人替你点确认。谁的货谁确认，这是以后查账的唯一依据。

看到单据卡在某个状态，对照这张表就知道该谁动手。全系统最常出现的「卡住」都在这里。

A. 出库单 / 领料单

状态意思该谁动手库存动了没
待确认领料员提交了，仓库还没受理仓管没动

B. 入库单

状态意思该谁动手库存动了没
已入库提交成功了。入库是「提交即入账」—（已经生效）已增加
已撤销发现填错，撤掉了—已回退
入库没有「待确认」 入库单提交就直接加库存，不会挂在中间状态。所以入库这一步要当场核对数量和单价。

C. 采购任务

状态意思该谁动手
待领取仓管发了任务，还没人接采购员
采购中采购员已领取，正在买采购员

收货中仓管在收，可能分批到货仓管
已入库全部收齐，办结—
已取消仓管取消了这个任务—

D. 盘点单

状态意思该谁动手
待开始建好了，还没录入仓管
盘点中开始录数了，还没提交仓管
待审核仓管提交了，等审厂长 / 管理员

盘点最容易烂尾的地方 卡在「待审核」。仓管盘完以为结束了，厂长没看到消息，账面就一直没改。 规矩：仓管提交后当面或电话通知厂长；厂长每天看一眼「盘点管理」的待审核。
