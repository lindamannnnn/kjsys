## 二、第一批 · 小程序 4 项

### 1. 仓管「采购任务」未结单角标

- **在哪看**：仓管工作台 → 「🛒 采购任务」卡片右上角，红底白字数字。
- **数字含义**：**未结单** = 待收料 + 收货中。
  > 这一条很重要：改成「到货即入库」之后，任务收到一半会停在「收货中」。
  > 如果角标只数「待收料」，仓管收到一半角标就归零，他会以为活干完了。
- 超过 99 显示 `99+`。

### 2. 采购员新任务数字提示

- **首页卡片**：「🛒 采购任务」右上角红点数字（= 可领取的任务数）。
- **任务列表**：顶部「待领取 / 待收料 / 收货中」tab 上各挂一个小数字，一眼看出哪个 tab 有活。

### 3. 采购渠道 6 项 + 「其他」必填备注

- **渠道**：淘宝、京东、1688、拼多多、线下、其他。
- **选「其他」时**：会多出一行「说明」，必须写清具体从哪买的（例：闲鱼二手）。
  不填提交会被拦下来，提示语会点名是哪个物料。
- **三层都有校验**：小程序、Web 后台、服务端各拦一次，绕不过去。
  > 为什么较真：只写「其他」两个字，月底对账时查不出这批货从哪来。
- **列表/详情里**显示成 `其他（闲鱼二手）`，不是干巴巴一个「其他」。

### 4. 厂长「成品仓出库」

- **入口**：厂长看板上的蓝色卡片「🚚 成品仓出库」。
- **流程**：厂长发起 → 单子到**成品仓管**那儿 → 仓管拣货 → 拣完自动通知厂长 → 厂长确认收货 → 完成。
- **进页面后是锁死成品仓的**（切换仓库的横条会消失），出库类型只有「销售 / 领用」。
- ⚠️ **后台改 URL 参数绕不过去**：服务端会按「物料实际属于哪个仓」再判一次。
  厂长如果夹带配件仓的物料，会被直接拒掉，提示语点名让他去找配件仓管。

## 三、第二批 · Web 后台 2 项

### 5. 后台按角色隔离（同一个网址，进来各是各的）

**网址不变**（还是你现在用的那个），登录后按身份进各自的后台：

| 身份 | 左上角显示 | 落地页 | 能看到的菜单 |
|---|---|---|---|
| 管理员 admin | 后台管理系统 | 数据看板 | 全部（含系统设置、批量导入、操作日志） |
| 老板 boss | 经营看板 | 数据看板 | 看板、大屏、数据统计、用户/权限、物料（两个仓）、单据、盘点、消息、操作日志（**不放**系统设置、批量导入） |
| 厂长 director | 厂长后台 | 数据看板 | 看板、出入库统计、配件仓+成品仓物料、单据、采购任务、盘点、消息 |
| 配件仓管 | 配件仓后台 | 数据看板 | 看板、出入库统计、**配件仓物料**、单据、采购任务、盘点、消息 |
| 成品仓管 | 成品仓后台 | 数据看板 | 看板、出入库统计、**成品仓物料**、单据、采购任务、盘点、消息 |
| 采购员 | 采购后台 | 采购任务 | 只给采购任务 + 消息 |
| 领料员 | 后台管理系统 | 消息中心 | 只有消息中心 |

**三层拦截**（所以「只能登入自己那套」是真的，不只是藏了菜单）：

1. **菜单**：不是你的就不显示（仓库维度也管：配件仓管看不到「成品仓物料」）。
2. **路由**：直接在地址栏敲越权网址，会被弹回自己的首页。
3. **接口**：真正的防线在服务端 —— 就算绕过前两层，接口照样 403。

**账号怎么开**（现在只有 admin 有后台账号，仓管/厂长还没有）：

> 用管理员登录后台 → 「用户管理」→ 「新增用户」→ 填【登录账号】+【密码】+【真实姓名】+【角色】+【可操作仓库】→ 保存。
> 之后这个人就能用这个账号密码登录后台了，进来自动是他自己那套。

- 一个「仓管」角色配了哪个仓，就只看得到哪个仓的物料；两个仓都配 → 左上角显示「仓库后台」。

### 6. 物料照片

- **后台显示**：「配件仓物料 / 成品仓物料」列表新增「**照片**」列；点缩略图可放大。没有照片的显示占位框。
- **怎么传**：物料列表 → 编辑 → 「物料照片」→ 上传照片（电脑选文件或手机拍都行）→ 保存。
- **小程序也显示**：领料选料、入库选料、仓管本仓库存三个列表，物料左边都有小图（没图显示占位）。

> ⚠️ **现在的实情**：1906 条物料里照片是 **0 张** —— 功能是通的，但库里还没有图，
> 所以打开列表会看到一整列占位框。要看到真图得先给物料传照片。
> 建议做法：仓管盘点时顺手用手机给常用料拍照上传，从高频的几十个料开始，不用一次铺满。

## 四、顺手修掉的两个老问题

1. **小程序冷启动时首页红点/角标全空**（真 bug）
   - 现象：杀掉小程序重进，消息红点、采购角标、待收货提醒有时候全不显示；退出再进又好了。
   - 根因：首页和启动流程**并发**跑登录检查，首页这边常常跑得早、令牌还没存下来，于是整块加载被跳过。
   - 现在：冷启动也能正确显示了。

2. **老板看板和厂长看板长得一模一样**
   - 两个身份共用同一页，但能做的事完全不同（厂长多一个「成品仓出库」，老板是纯只读）。
   - 现在页面左上角会写清「老板」/「厂长」，不会再有「是不是功能少了」的误会。

## 五、怎么验收（照做即可）

### 小程序（微信开发者工具 / 真机）

1. **仓管**登录 → 工作台「采购任务」卡片右上角有数字。
2. **采购员**登录 → 首页「采购任务」卡片右上角有数字；点进列表，tab 上也有小数字。
3. **采购员** → 随便领一个任务 → 录单价那一步，点「其他」→ 会多出一行「说明」，空着提交会被拦；点「1688」→ 说明行自动收起。
4. **厂长**登录 → 看板出现蓝色「成品仓出库」→ 点进去，切仓横条不见了（锁死成品仓）→ 提交后
   换**成品仓管**登录，会在待办里看到这单，拣货完成 → 厂长收到通知 → 厂长点确认 → 单据完成。

### Web 后台

5. 用管理员给「配件仓管」「厂长」各开一个账号（见上文）。
6. 分别用这些账号登录后台，看：左上角身份名对不对、菜单是不是只有自己那几项。
7. 复制一个别人的网址（比如仓管账号去敲 `/user/list`），确认被弹回自己的首页。
8. 用仓管账号进「配件仓物料」，确认有「照片」列，并且编辑页能传图。

## 七、已知限制 / 没做的事

1. **物料照片库里 0 张**：功能通，但要有图得人工传（见上文建议）。
2. **小程序里的照片在正式环境有域名限制**：微信小程序只能从**已备案的 HTTPS 域名**下载图片。
   本地/开发工具能看，正式发布前必须先把域名换掉（这件事本来就在你的发布清单里，不影响现在用）。
3. **后台账号要手工开**：仓管、厂长目前没有后台账号，需要管理员在「用户管理」里建。
   没有做「批量导入员工账号」，如果人多可以再提。
4. **老板和厂长共用「数据看板」这一页**：数字口径一样，靠页面左上角的身份标识和「成品仓出库」入口区分。
   如果你希望两个角色拆成两个不同页面（各自排版），可以再提，属于改版不是修 bug。
5. **`favicon.ico` 会有一个 404**：后台页面加载时浏览器会请求网站图标，我们没放图标文件。
   纯粹是控制台的噪音，不影响任何功能，也不影响用户看到什么。
