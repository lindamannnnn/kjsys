# 投产操作手册（正式启用当天照着做）

> 给谁看：你自己 + 厂长。
> 什么时候用：域名、微信登录、企微都配好之后，正式启用那一天。
> 按顺序做，每步做完打个勾。

---

## 第一步 · 启用前确认（先别清数据）

- [ ] 浏览器打开 `https://sl.ekkosys.cn/admin/` 能打开后台登录页
- [ ] 手机上小程序能打开（微信开发者工具或体验版）
- [ ] WX_SECRET 已填进生产 `.env`（微信登录能用）
- [ ] 企微三样已填进生产 `.env`（要推送的话）
- [ ] **先盘点**：把配件仓、成品仓的实物数量点数点清楚，记下来

---

## 第二步 · 数据清 0（清掉试用期的数据）

⚠️ 这一步会把试用期的单据、流水、库存数字都清掉，物料档案和员工账号保留。**先确认你已经盘点完、记好实盘数**。

```bash
# 在生产服务器上跑（SSH 上去）
cd /opt/shenglong/server
node src/db/reset-production.js          # 先看预览：会清什么、留什么
node src/db/reset-production.js --yes    # 确认后执行（会要你输入「确认清0」，并自动备份）
```

清完：库存全 0、单据全空、测试账号删掉，物料档案和真实员工账号还在。

---

## 第三步 · 录期初库存（把实盘数录进去）

1. 用 Excel 打开 `期初库存导入模板.csv`（里面已经预填了所有物料）。
2. 对照盘点结果，填两列：**实盘数量**、**期初单价**（单价不填就按 0，以后真实采购入库会自动更新）。
3. 没货的料数量填 0 或留空（会跳过）。
4. 另存为 CSV，然后跑：

```bash
cd /opt/shenglong/server
node scripts/init-stock.js 期初库存导入模板.csv --dry-run   # 先演练：看匹配对不对，不写库
node scripts/init-stock.js 期初库存导入模板.csv            # 确认无误后正式建账
```

✅ 跑完：每个仓生成一张「期初建账」入库单，库存就按实盘进来了，库存流水里有记录（责任人=管理员）。

---

## 第四步 · 员工账号和角色

在后台 `https://sl.ekkosys.cn/admin/`（用管理员账号登录）：

- [ ] 「用户管理」里给每个员工建账号 / 核对已有账号
- [ ] 给每人**分配角色**（领料员 / 采购员 / 仓管 / 厂长 / 老板）
- [ ] 仓管、厂长这类要收通知的，**填上「企微账号」**（企业微信里的成员账号）
- [ ] 仓管要选好「可操作仓库」（配件仓管只管配件仓、成品仓管只管成品仓）

---

## 第五步 · 员工进小程序

- [ ] 员工用微信扫小程序码进入
- [ ] 第一次进会微信登录 → 进来后看到的是默认身份，**需要管理员在后台给他分配角色**（第四步）
- [ ] 分配好角色后，员工重新进小程序，首页就只显示他该用的功能了

---

## 第六步 · 试一单，确认真能用

随便走一单，验证整条链：
- [ ] 仓管在小程序「入库登记」入一笔料 → 库存加了
- [ ] 领料员「领料出库」→ 仓管确认 → 领料员收货 → 库存扣了
- [ ] 配了企微的话，对应的人企微收到通知
- [ ] 老板/厂长打开看板，数字对

---

## 常见问题

| 情况 | 怎么办 |
|---|---|
| 员工扫进来没看到功能 | 后台还没给他分配角色，去「用户管理」分配 |
| 企微收不到通知 | 检查生产 .env 的企微三样 + 用户的企微账号填了没；跑 `node scripts/test-wecom.js 某人的企微账号` 自测 |
| 小程序提示网络异常 | 检查手机是否连网；确认小程序后台「服务器域名」配了 `https://sl.ekkosys.cn` |
| 库存数字不对 | 看「库存流水」——每笔出入库都有记录和责任人 |
