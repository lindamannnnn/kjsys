### 遇到的问题

1. **接口把密码哈希返回给了前端（严重安全漏洞）**
   - 现象：登录接口响应里含 `password_hash` 字段
   - 根因：`utils/format.js` 的 `toApi()` 直接复制整行数据库记录
   - 修复：新增 `SENSITIVE_FIELDS` 白名单过滤，密码类字段一律不对外返回
   - 预防：所有对外转换统一走 `toApi()`，字段剔除只在这一处维护

2. **`ctx.user.id` 变成 undefined，导致「管理员不能禁用自己」校验失效**
   - 现象：测试后 admin 账号真的被禁用了
   - 根因：`toApi()` 把主键 `id` 改名成 `_id`（为了前端兼容），
     服务端代码却仍在用 `ctx.user.id`
   - 修复：`loadUser()` 在返回对象上把数字主键 `id` 补回来
   - 预防：**对外字段名与内部字段名分开维护**，内部逻辑一律用 `id`

3. **测试因残留数据误报 5 项失败**
   - 现象：第二次跑测试出现「库存累计 200 → 实际 388」等 5 项失败
   - 根因：第一次测试中途异常退出，没执行收尾清理，库里留了数据
   - 修复：测试开头先做一次「起点复位」（清残留单据 + 测试物料归零）
   - 预防：测试必须自我复位，不能依赖上一次正常结束

4. **Docker 拉不到官方镜像**
   - 现象：`docker compose up -d mysql` 报 `failed to resolve reference "docker.io/library/mysql:8.0"`
   - 修复：改用 `docker.1panel.live/library/mysql:8.0` 拉取后重新打标签
   - 已写入 `docs/LOCAL-DEV.md` 常见问题，服务器部署时同样适用

5. **npm 安装依赖空闲超时失败**
   - 现象：`EIDLETIMEOUT`，且失败后回滚把已装好的 express/mysql2/cors 删掉了
   - 修复：加大 `--fetch-timeout` 与 `--fetch-retries`，补装缺失的三个包

6. **子代理发现的接口短板（已修）**
   - 导出功能只能取到 200 条（`paging()` 上限截断），已改为支持 `forExport` 放宽到 5000 条，
     前端循环分页拉全量
   - 出库/入库列表缺少按类型筛选，已补 `type` 参数

### 续记（当晚）：修「模拟器启动失败：未找到 app.json」

2. `project.private.config.json` 的 `urlCheck` 由 `true` 改 `false`（否则连不上本地后端）
3. 新增 `npm run mp:open`（`miniprogram/scripts/open-devtools.js`），自动用开发者工具打开正确目录
