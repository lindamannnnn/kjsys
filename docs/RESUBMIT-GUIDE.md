## 二、域名方案：借 `ekkosys.cn` 子域名

### 为什么这条能走通

微信对 `request` 合法域名的硬性要求（四个独立来源口径一致）：

1. 必须完成 **ICP 备案**，且**备案主体要与小程序主体一致**
2. 必须 **HTTPS**（TLS 1.2+），不能用 IP
3. 不能用免费二级域名、localhost

主体核对：

| 项 | 值 | 一致？ |
|---|---|---|
| 小程序认证主体 | 个人（你本人） | — |
| `ekkosys.cn` 备案主体 | 个人（你本人） | ✅ |

**主体一致，这关能过。** 子域名不需要单独备案——主域名备案通过后自动享有。

### 要做的 7 步

#### 步骤 1：加一条 DNS 解析

在 `ekkosys.cn` 的 DNS 管理后台（域名在哪个平台注册的就去哪个平台的「云解析」）新增：

| 记录类型 | 主机记录 | 记录值 | TTL |
|---|---|---|---|
| A | `sljxc`（或你喜欢的名字） | `119.91.206.235` | 600 |

最终域名形如 `sljxc.ekkosys.cn`。

> ⚠️ 这一步只加一条记录，**不要动 ekkosys.cn 上已有的解析**（Ekko 项目还在跑）。

#### 步骤 2：在腾讯云提交「新增接入备案」（必做）

备案是跟**接入商**绑定的。`ekkosys.cn` 目前在阿里云接入，解析到腾讯云后，腾讯云会要求把接入也备过来，否则访问可能被拦。

- 入口：腾讯云控制台 → 备案 → **新增接入**
- 填写域名：`ekkosys.cn`
- 材料：身份证、域名证书（阿里云控制台可下载）
- 耗时：腾讯云初审 1-2 个工作日 → 提交广东省管局 → 一般 3-7 个工作日（最长 20 个）

> 这一步**不能省**。跳过它，域名解析生效了也可能被腾讯云拦下。
> 好消息：这是「接入」不是「首次备案」，比新域名第一次备案快很多。

#### 步骤 3：申请 HTTPS 证书

- 腾讯云控制台 → SSL 证书 → 申请免费 DV 证书，绑定 `sljxc.ekkosys.cn`
- 或用 Let's Encrypt（免费，90 天，需配自动续期）
- 也可以买一张 1 年期 DV 证书（几十元，省心）

> 证书过期会导致请求全部失败，务必配好到期提醒或自动续费。

#### 步骤 4：服务器配置（要小心，**不能动原有内容**）

服务器上目前是 Node 直接跑在 `3000` 端口，没有 nginx。需要：

1. ~~先确认 `80` / `443` 端口空闲~~ → **已确认：80/443 均空闲**（服务器上原有的 8899 端口 Python 服务、`/opt/node` 等**一律不碰**）
2. 安装 nginx（**当前服务器上还没装**），配置一个**独立站点**：`443` → 反代到 `127.0.0.1:3000`
3. 上传证书、开 TLS
4. 建议同时加一条：`80` → 301 跳 `443`

nginx 配置文件建议放在 `/etc/nginx/conf.d/sljxc.conf`，**不要改 nginx 默认站点的既有文件**，避免影响服务器上其他东西。

#### 步骤 5：改小程序接口地址

`miniprogram/src/utils/cloud.js`：

```js
// 现在（正式版会被微信拦）
const API_BASE = 'http://119.91.206.235:3000'

// 改成
const API_BASE = 'https://sljxc.ekkosys.cn'
```

改完要重新构建：`npm run build:mp-weixin`。

#### 步骤 6：微信后台配置合法域名

微信公众平台 → 开发 → 开发管理 → 开发设置 → **服务器域名**：

- `request 合法域名`：`https://sljxc.ekkosys.cn`

保存后约 5-10 分钟生效。

#### 步骤 7：重新提审

用第三节的备注文案 + 第四节的录屏一起提交。

## 四、录屏脚本（建议 1-2 分钟）

按这个顺序录，正好覆盖审核员最想确认的点：

1. **打开小程序 → 未登录首页**（停留 3 秒，让审核员看清系统介绍和功能列表是可见的）
2. 点开《用户服务协议》→ 返回 → 点开《隐私政策》→ 返回（证明协议真实存在、可访问）
3. 点「登录」→ **不勾选直接点登录**（展示会提示"请先阅读并同意协议"）
4. 勾选同意 → 微信登录 → 进入首页
5. **演示一条完整业务链**：领料出库提交 → 仓管审核 → 库存变化
6. 切换到「老板看板」，展示库存数据（证明功能真实可用、数据真实）

> 录制要点：全程真机录屏，不要用开发者工具（审核员要看真实运行效果）。
