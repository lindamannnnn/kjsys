# 盛龙进销存 · 全流程测试手册

> 用途：把系统从头到尾测一遍，每个功能都过手。
> 分两层：**自动化层**（一条命令跑 642 项接口断言 + 32 项真实浏览器断言，几分钟出结果）+
> **手动层**（本手册主体，逐项打勾，测「人看起来的样子」——文案、交互、顺手程度）。
> 建议顺序：先跑自动化（绿了再手动），手动按岗位走。

## 1. 自动化层（先跑这个）

```bash
cd shenglong-erp/server
npm run test:roleagent     # 接口 3 轮 × 5 岗位（642 项断言）+ 真实浏览器 UI（32 项）
```

- 全绿 → 进入手动层
- 有红 → 报告在 `server/tests/role-agent/results/`，修完再跑
- 测完想回到干净演示态：`node tests/cleanup-test-data.js --apply`

自动化已覆盖：四条业务链路全流程、权限门、越权、误操作（连点/乱填/超额/重复）、两端看板一致性、账面=流水对账。**手动层重点测它覆盖不到的：界面观感、文案、操作顺手度、真实交互。**
